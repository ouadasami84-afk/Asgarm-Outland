# **App Name**: Arcanum Prime

## Core Features:

- Cinematic Hero Gateway: A high-fidelity landing experience featuring volumetric fog, parallax layers of ancient structures, and scroll-triggered lighting effects to set a AAA-game mood.
- Lore Weaver Tool: An AI-powered storytelling tool that generates personalized magical backstories and world-building narratives based on user input, using generative reasoning to ensure consistency with the app's mythology.
- Enchanted Artifact Gallery: A luxury-themed showcase using frosted glass cards and gold-accented borders to display magical items with interactive 3D-tilt animations.
- Rune Discovery Interactive: An interactive section where users engage with animated magical energy circles and mouse-following particle systems that mimic ancient rune-casting.
- World Atlas Navigator: A horizontal-scrolling world showcase using large, cinematic-quality image transitions and fluid GSAP-driven movement to explore different magical biomes.
- Mastery Ledger: A database-integrated dashboard for users to track their progression, unlock legendary status achievements, and persist their custom lore to a Cloud SQL backend.

## Style Guidelines:

- The palette is anchored in a dark, luxury fantasy aesthetic. The background is a Deep Obsidian (#080808), providing a premium foundation. The primary color is a rich Arcane Violet (#5A2D91) used for glowing elements, contrasting against Enchanted Gold (#D4AF37) accents for critical call-to-action buttons.
- Headlines use 'Playfair', a high-contrast serif that evokes an epic, high-end literary feel. For optimal legibility and a modern SaaS-like touch, body text uses 'Inter' to maintain a clean, machined, and professional layout.
- An ultra-premium, desktop-first design utilizing generous whitespace, precise spacing, and cinematic proportions, echoing a hybrid of Apple-level minimalism and high-end video game interfaces.
- Fluid interactions powered by Framer Motion and GSAP, featuring subtle magical glows, depth-focused parallax transitions, and reactive particle physics for every mouse movement.
- Hand-crafted, elegant minimalist icons featuring thin-stroke geometry and subtle gold gradients to signify various magical disciplines.
